# Flask Claude Example - GitHub Pages Demo

This directory contains a static demo version of the Flask Claude Example application, designed to be deployed on GitHub Pages.

## 🌐 Live Demo

Visit the live demo: **[https://freewimoe.github.io/flask-claude-example/](https://freewimoe.github.io/flask-claude-example/)**

## What's Included

- **Static HTML Pages**: All major UI components converted to static HTML
- **Interactive Forms**: Demonstration forms with JavaScript feedback
- **Complete Styling**: Original CSS with responsive design
- **Feature Overview**: Comprehensive showcase of all application features

## Pages Available

- `index.html` - Homepage with sample blog posts and feature overview
- `login.html` - Login form demonstration
- `register.html` - Registration form demonstration  
- `create_post.html` - Blog post creation interface
- `upload_file.html` - File upload interface with security features overview

For full functionality including:

## Deployment

This demo is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the main branch.

The deployment workflow:
1. Builds the static site from the `docs/` directory
2. Deploys to GitHub Pages
3. Makes the demo available at the GitHub Pages URL
